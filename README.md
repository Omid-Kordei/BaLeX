## 📖 معرفی

**BaleX** یک اپلیکیشن اندرویدی است که به شما امکان می‌دهد **ربات‌های پیام‌رسان بله** را مستقیماً از روی گوشی خود، بدون نیاز به هاست، سرور یا کدنویسی، مدیریت کنید. کافیست توکن رباتتان را وارد کنید تا بتوانید مثل یک اپ چت معمولی با کاربرانی که به ربات پیام می‌دهند گفتگو کنید، فایل و لوکیشن بفرستید و پیام‌ها را دنبال کنید.

این پروژه در ابتدا برای استفاده‌ی شخصی نوشته شده و اکنون به صورت **متن‌باز (Open Source)** منتشر می‌شود تا دیگران هم بتوانند از آن استفاده کرده و در توسعه‌اش مشارکت کنند.

> ⚠️ BaleX یک پروژه‌ی مستقل و غیررسمی است و هیچ ارتباط رسمی با شرکت پیام‌رسان بله ندارد. این اپ صرفاً از **Bot API عمومی بله** استفاده می‌کند.

## ✨ کاربردها و امکانات

- 🔑 **ورود با توکن ربات** — بدون نیاز به ساخت اکانت جداگانه؛ فقط توکنی که از بله گرفته‌اید را وارد کنید.
- 💬 **لیست چت‌ها** — نمایش تمام گفتگوهای ربات (خصوصی/گروه) با قابلیت فیلتر بین «همه»، «خصوصی» و «گروه».
- 📩 **ارسال و دریافت پیام** به‌صورت تقریباً بلادرنگ (از طریق Long Polling).
- ↩️ **پاسخ به پیام (Reply)** درون گفتگو.
- 📎 **ارسال فایل، عکس و آهنگ** از گالری/فایل‌های گوشی.
- 📍 **ارسال موقعیت مکانی (Location)** با استفاده از GPS گوشی.
- 🗂️ **ذخیره‌ی محلی پیام‌ها و چت‌ها** روی حافظه‌ی داخلی گوشی (بدون سرور واسط).
- 📋 **کپی سریع توکن** و مشاهده‌ی اطلاعات پروفایل ربات (نام، یوزرنیم، آیدی عددی).
- 🐞 **صفحه‌ی لاگ خطاها** برای رهگیری و رفع مشکلات شبکه/ای‌پی‌آی.
- 🚪 **خروج از حساب (Logout)** با پاک‌سازی کامل توکن از حافظه‌ی گوشی.
- 🎨 رابط کاربری ساده، انیمیشن‌دار و مناسب زبان فارسی (راست‌به‌چپ).

- نام نمایشی اپ از `app/src/main/res/values/strings.xml` (`app_name`) خوانده می‌شود.
- برای شخصی‌سازی/فورک کردن پروژه با برند خودتان، کافیست همین سه مورد (آیکون، رنگ‌ها، نام) را جایگزین کنید؛ نیازی به تغییر ساختار کد نیست.

## 🧱 معماری و ساختار پروژه

پروژه با **Java خالص** و **Android SDK** نوشته شده (بدون فریم‌ورک شخص‌ثالث سنگین) و از الگوی ساده‌ی Activity + Helper Classes پیروی می‌کند:

```
BaleX/
├── app/
│   ├── build.gradle                 # تنظیمات ماژول اپ (SDK، وابستگی‌ها)
│   ├── proguard-rules.pro
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/ir/BaleX/
│       │   ├── MainActivity.java        # صفحه‌ی ورود با توکن
│       │   ├── HomeActivity.java        # صفحه‌ی اصلی (لیست چت‌ها، چت‌روم، تنظیمات)
│       │   ├── BaleApi.java             # لایه‌ی ارتباط با Bot API بله (HTTP)
│       │   ├── PollingManager.java      # دریافت پیام‌های جدید با Long Polling
│       │   ├── StorageHelper.java       # ذخیره‌سازی محلی چت‌ها/پیام‌ها (JSON روی فایل)
│       │   ├── FileDownloader.java      # آماده‌سازی و دانلود فایل‌های رسانه‌ای
│       │   ├── FileUtil.java            # ابزارهای کار با فایل
│       │   ├── ChatAdapter.java         # آداپتور لیست چت‌ها
│       │   ├── MessageAdapter.java      # آداپتور لیست پیام‌ها در چت‌روم
│       │   ├── LogHelper.java           # ثبت و نمایش لاگ خطاها
│       │   ├── ProfileCache.java        # کش اطلاعات پروفایل کاربران/چت‌ها
│       │   ├── SketchwareUtil.java      # ابزارهای عمومی UI
│       │   ├── ReplyState / PendingUpload / IncomingMessage / ChatOpener
│       │   └── ...
│       └── res/                     # لایه‌بندی‌ها (layout)، انیمیشن‌ها، آیکون‌ها، رنگ‌ها
├── build.gradle                     # تنظیمات پروژه (سطح ریشه)
├── settings.gradle
└── gradle.properties
```

### جریان کار کلی (Flow)
1. کاربر توکن ربات را در `MainActivity` وارد می‌کند → با متد `getMe` صحت‌سنجی می‌شود.
2. در صورت صحیح بودن، توکن و اطلاعات ربات در `SharedPreferences` ذخیره شده و کاربر به `HomeActivity` هدایت می‌شود.
3. `PollingManager` در پس‌زمینه با متد `getUpdates` بله، پیام‌های جدید را واکشی می‌کند.
4. پیام‌ها و چت‌ها با `StorageHelper` به‌صورت فایل‌های JSON در حافظه‌ی داخلی اپ ذخیره می‌شوند.
5. ارسال پیام/فایل/لوکیشن از طریق متدهای `BaleApi` (که مستقیماً روی `HttpURLConnection` پیاده‌سازی شده) انجام می‌شود.

## 🔐 نکات و ملاحظات امنیتی (Security Notes)

این بخش را حتماً پیش از استفاده یا مشارکت در توسعه بخوانید:

1. **ذخیره‌سازی توکن به‌صورت متنی و بدون رمزنگاری**
   توکن ربات در `SharedPreferences` معمولی (`MODE_PRIVATE`) ذخیره می‌شود و رمزنگاری نشده است. در گوشی‌های روت‌شده یا با دسترسی فیزیکی، توکن قابل استخراج است.
   → پیشنهاد برای توسعه‌دهندگان: استفاده از `EncryptedSharedPreferences` (بخشی از Jetpack Security) برای نسخه‌های بعدی.

2. **`usesCleartextTraffic="true"` در Manifest**
   این پرچم اجازه‌ی ترافیک HTTP غیررمزنگاری‌شده را می‌دهد. در حال حاضر تمام درخواست‌ها به `https://tapi.bale.ai` (HTTPS) ارسال می‌شوند، اما این تنظیم باید در آینده محدودتر شود تا از اتصال ناخواسته به آدرس‌های HTTP جلوگیری شود.

3. **عدم استفاده از Certificate Pinning**
   ارتباط با API صرفاً از HTTPS استاندارد سیستم استفاده می‌کند؛ در برابر حملات پیشرفته‌ی MITM (مثلاً با نصب گواهی جعلی روی دستگاه) محافظت اضافه‌ای وجود ندارد.

4. **پیام‌ها و فایل‌ها به‌صورت رمزنگاری‌نشده روی حافظه‌ی داخلی ذخیره می‌شوند**
   اگرچه Internal Storage اندروید به‌طور پیش‌فرض برای اپ‌های دیگر قابل‌دسترس نیست، اما در دستگاه‌های روت‌شده یا هنگام تهیه‌ی بکاپ کامل (`allowBackup="true"`) این داده‌ها می‌توانند در معرض دسترسی قرار بگیرند.

5. **مجوزهای حساس**
   اپ به `ACCESS_FINE_LOCATION` و `ACCESS_COARSE_LOCATION` نیاز دارد (صرفاً برای قابلیت ارسال لوکیشن). این مجوزها فقط زمانی درخواست می‌شوند که کاربر روی گزینه‌ی «ارسال لوکیشن» بزند.

6. **توکن = دسترسی کامل به ربات**
   هرکسی که توکن ربات شما را داشته باشد می‌تواند به‌جای شما پیام بفرستد، تنظیمات ربات را تغییر دهد و به گفتگوهای آن دسترسی داشته باشد. توکن را هرگز در اسکرین‌شات، ریپازیتوری گیت (کد منبع)، یا با افراد غیرقابل‌اعتماد به اشتراک نگذارید. اگر توکن لو رفت، بلافاصله از طریق بله آن را ریست/ریوک کنید.

7. **بدون سرور واسط**
   BaleX هیچ سروری از خودش ندارد؛ تمام ارتباطات مستقیماً بین گوشی شما و سرور بله برقرار می‌شود. یعنی توسعه‌دهندگان این پروژه به هیچ داده یا پیامی از ربات شما دسترسی ندارند.

> 🙏 مشارکت‌کنندگان محترم: هرگونه Pull Request که به بهبود موارد بالا کمک کند (رمزنگاری توکن، Certificate Pinning، محدود کردن Cleartext Traffic و ...) با استقبال ویژه پذیرفته می‌شود.

## 🚀 راه‌اندازی و بیلد پروژه

### پیش‌نیازها
- [Android Studio](https://developer.android.com/studio) (نسخه‌ی Hedgehog به بعد توصیه می‌شود)
- JDK 17
- Android SDK با `compileSdk 34`

### مراحل
```bash
git clone https://github.com/<username>/BaleX.git
cd BaleX
```
سپس پروژه را در Android Studio باز کنید (`Open an existing project`)، بگذارید Gradle Sync کامل شود و روی دستگاه/شبیه‌ساز اجرا کنید (`Run ▶`).

### گرفتن توکن ربات بله
۱. به [ربات BotFather بله](https://ban.bale.ai) یا مستندات [dev.bale.ai](https://dev.bale.ai) مراجعه کنید.
۲. یک ربات جدید بسازید و توکن آن را کپی کنید.
۳. توکن را در صفحه‌ی ورود BaleX وارد کنید.
